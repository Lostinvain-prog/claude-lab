# CLAUDE.md

Этот файл содержит указания для Claude Code (claude.ai/code) при работе с кодом в этом репозитории.

## Проект

«Полка Lostinvain» — статическая одностраничная личная коллекция игр. Чистые HTML, CSS и JavaScript, без сборки, без пакетного менеджера и тестов. Язык страницы — русский (`lang="ru"`), весь текст интерфейса на русском.

## Запуск

Поднять любой статический сервер в папке проекта, например:

```
python -m http.server 8000
```

Открывать `index.html` напрямую по `file://` нельзя: стартовые карточки подгружаются через `fetch`, который браузер блокирует для локальных файлов. Полка при этом откроется, но пустой.

## Структура

- `index.html` — шапка, вкладки `.tabs` («Любимые», «Играл», «Тирлист»; «Играл» открыта по умолчанию), блок `#collection-view` (форма добавления, поиск, фильтр по тегам, панель `.shelf-toolbar` с сортировкой `#sort-select` и экспортом `#export-btn`, секция-сетка `.shelf`), секция `#tierlist` и подвал. Карточки `<article class="game-card">` рисует скрипт из localStorage.
- `data/cards.json` — стартовые карточки. `app.js` загружает их через `fetch` только при первом открытии (когда в localStorage ещё нет карточек) и сразу записывает в хранилище; дальше файл не читается.
- `app.js` — вся логика полки: хранилище, вкладки, форма, поиск, теги, сортировка. Инициализация в `DOMContentLoaded` асинхронная: ждёт `initCards()`. Массив карточек под ключом `shelf-cards` — единственный список игр, поля `collection` у карточек больше нет. Вкладка «Играл» показывает все карточки; «Любимые» — подмножество, отмеченное сердечком `.game-fav` на карточке. Названия любимых лежат отдельным массивом под ключом `shelf-favorites` (`["Dota 2", "Kenshi"]`, идентификация по `title`); при загрузке старые записи с `collection: "favorite"` один раз мигрируют в этот ключ. Глобальные функции `loadFavorites()` и `isFavorite(title)` доступны другим скриптам. Новая карточка из формы всегда попадает в «Играл», а с открытой вкладки «Любимые» ещё и помечается любимой. Активная вкладка лежит в localStorage под ключом `shelf-tab`, по умолчанию — «Играл». Массив карточек в хранилище всегда в порядке добавления; сортировка только визуальная, режим лежит под ключом `shelf-sort`. Индекс карточки в общем массиве хранится в `data-index` на `article`, а не берётся из позиции в DOM. После смены вкладки app.js шлёт событие `shelf:tab` (в `detail.tab` имя вкладки), после любого изменения карточек — `shelf:cards-changed`.
- `export.js` — экспорт коллекции в JSON-файл по кнопке. Подключён после `app.js` и использует его глобальные функции (`loadCards`), поэтому порядок `<script>` менять нельзя.
- `tierlist.js` — вкладка «Тирлист»: обложки всех карточек раскладываются перетаскиванием (HTML5 Drag and Drop) по рядам S–D и зоне «Не распределено». Раскладка хранится в localStorage под ключом `shelf-tierlist` как `{ "S": ["Название", …], … }`; карточки идентифицируются по названию. Перерисовывается по событиям `shelf:tab` и `shelf:cards-changed`, читает карточки через `loadCards()`, поэтому подключён после `app.js`.
- `notes.js` — мнения об играх: клик по карточке `.game-card` (кроме кнопок `.game-actions` и чипов `.game-tag`) открывает `<dialog id="note-dialog">` с textarea; на карточке с мнением рисуется блок `.game-note` с первыми ~100 символами. Мнения хранятся в localStorage под ключом `shelf-notes` как `{ "Название": "текст", … }`; записи для удалённых карточек подчищаются при перерисовке. Блоки дорисовываются по `DOMContentLoaded`, событиям `shelf:tab` и `shelf:cards-changed` и через MutationObserver на `.shelf`, потому что app.js перерисовывает полку без события. Читает карточки через `loadCards()`, подключён последним.
- `styles.css` — тёмная тема на CSS-переменных из `:root` (`--bg`, `--surface`, `--accent` и др.). Использовать эти переменные, а не жёстко прописанные цвета. `.shelf` — адаптивная сетка `auto-fill`, у карточек при наведении подъём и свечение.

## Правила

- Данные карточек хранятся в localStorage.
- Обложка по умолчанию — эмодзи. Если у карточки нет обложки, показывать эмодзи, а не пустое место.
- JavaScript — только ванильный, без сборки и без библиотек.
- Новые библиотеки не подключать.
- Все комментарии в коде — на русском.
- Сборки и тестов нет; проверка — открыть `index.html` в браузере.
